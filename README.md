# Egyptian Mythology (legacy)

Guide and quiz on Egyptian mythology: gods, myths and glossary.

This repository holds the original native Android app (Java). It is archived and no longer maintained.
The app is now developed in Flutter at [netersoft/egyptian-mythology](https://github.com/netersoft/egyptian-mythology).
The new app keeps the same application id, so it ships on the [Play Store](https://play.google.com/store/apps/details?id=com.neteru.ankh) as an update of this one.

## Project

- Application id: `com.neteru.ankh`
- Version in this repository: 1.3.5
- Android Studio project (Gradle), `minSdkVersion` 16

The project targets the Android SDK and Gradle versions of its time and is not expected to build as is with current tools.
